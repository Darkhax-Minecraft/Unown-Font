<!-- description-start -->
This is the official GitHub repo for the Unown-Font mod. Adds a font inspired by the unown characters to Minecraft. You can download this mod from [CurseForge](https://www.curseforge.com/minecraft/mc-mods/unown-font) or [Modrinth](https://modrinth.com/mod/unown-font). Please report issues [here](https://github.com/Darkhax-Minecraft/Unown-Font/issues).
<!-- description-end -->

## Maven Dependency
This project is available on the [BlameJared Maven](https://maven.blamejared.com).

If you are using [Gradle](https://gradle.org) you can add the mod as a dependency by adding the following
to your `build.gradle` file.

```groovy
repositories {
    maven {
        url 'https://maven.blamejared.com'
    }
}

dependencies {
     // NeoForge
     implementation group: 'net.darkhax.unownfont', name: 'unownfont-neoforge-26.2', version: '26.2.0.0'
     // Fabric
     implementation group: 'net.darkhax.unownfont', name: 'unownfont-fabric-26.2', version: '26.2.0.0'
     // Common / MultiLoader / Vanilla / No Loader
     implementation group: 'net.darkhax.unownfont', name: 'unownfont-common-26.2', version: '26.2.0.0'
}
```
